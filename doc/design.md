# サイト設計書

2026年の日本国内トップカテゴリー（スーパーフォーミュラ、SUPER GT、スーパー耐久）を、公式情報をもとに比較・閲覧する静的サイト。

- [トップページ](#トップページ)
- [スーパーフォーミュラ](#スーパーフォーミュラ)
- [SUPER GT](#super-gt)
- [スーパー耐久](#スーパー耐久)

## サイト全体

### 目的

- 3カテゴリーのレギュレーションと年間日程を1画面で比較できるようにする
- 各カテゴリーのチーム／ドライバーランキングと、チーム周辺情報（スポンサー、監督、ドライバー、レースアンバサダー）を確認できるようにする
- 公式サイト・公式マシン画像・確認できた個人SNSへ直接たどれるようにする

### 対象読者

モータースポーツ観戦者。専門用語は必要最小限にし、日本語で記述する。

### サイトマップ

```text
index.html
  └─ 即時リダイレクト
      └─ 2026_japanese_car_race_category/
          ├─ index.html              トップページ
          ├─ super_formula/index.html
          ├─ super_gt/index.html
          └─ super_taikyu/index.html
```

| パス | 役割 |
| --- | --- |
| `index.html` | ルート入口。トップページへ `meta refresh` で転送する |
| `2026_japanese_car_race_category/index.html` | 3カテゴリーの規定・日程を横並びで見るページ。サイトの実質トップ |
| `2026_japanese_car_race_category/super_formula/index.html` | スーパーフォーミュラのランキング・チーム情報 |
| `2026_japanese_car_race_category/super_gt/index.html` | SUPER GT のランキング・チーム情報 |
| `2026_japanese_car_race_category/super_taikyu/index.html` | スーパー耐久のクラス別ランキング・チーム情報 |

### 技術方針

- ビルドなしの静的 HTML。CSS は各ページの `<style>` に内包する
- 画像・ロゴは公式サイトの直リンクを使う。ローカルアセットは持たない
- 外部リンクは `target="_blank"` と `rel="noopener"` を付ける
- 言語は `lang="ja"`、文字コードは UTF-8

### 画面構成の共通ルール

1. ページタイトル（`h1`）
2. 公式ロゴ（公式トップへのリンク）
3. 時点注記（`.note`）
4. ページ間ナビ（ピル型リンク）
5. 本文テーブル
6. 出典キャプション（表の下）

ランキングページのナビは「トップページに戻る」と他2カテゴリーへの相互リンクで揃える。

### 配色

カテゴリー識別色はサイト全体で固定する。取り違えない。

| 用途 | 色 | 使途 |
| --- | --- | --- |
| スーパーフォーミュラ | `#1f7a4d` | トップページの列見出し、SFページのキーカラー |
| SUPER GT | `#b0182a` | トップページの列見出し、GTページのキーカラー |
| スーパー耐久 | `#0b5fa5` | トップページの列見出し、S耐ページのキーカラー |
| トップページヘッダー／分類ラベル | `#1a2a4a` | トップページの表頭とセクションラベル |
| サーキット出典バッジ | `#6a3fa0` | トップページのサーキット公式リンク |
| チケット出典バッジ | `#9a4d00` | トップページのチケット案内リンク |
| 本文 | `#1f2733` | 文字色 |
| 補足 | `#667285` または `#5f6b79` | 時点注記・キャプション |
| 背景 | `#f4f6f9` | ページ背景 |
| 枠線 | `#d8dde3` | テーブル罫線 |

リンクは本文色を継承し、下線は点線、ホバーで実線にする。ロゴ・チーム画像のリンクは下線を消す。

### タイポグラフィ

- フォント: `"Hiragino Sans", "Yu Gothic", "Segoe UI", Arial, sans-serif`
- 本文・セル: おおよそ `0.86rem`、行間 `1.6`〜`1.65`
- 見出しはカテゴリーキーカラー（トップページのみネイビー）

### コンテンツ方針

#### 出典

- ランキング・規定・日程は公式（または公式が引用しているメーカー公式）を優先する
- 表の下に出典キャプションを置く
- トップページの個別セルには、カテゴリー色の出典バッジを付ける

#### 時点

各ページ先頭に「いつの情報か」を書く。現行は、SUPER GT ページが2026年8月24日時点、トップページ・他ページが2026年8月時点（8月14日更新）。

| ページ | ランキング基準 |
| --- | --- |
| トップページ | 2026年シーズンの最新規定・日程 |
| スーパーフォーミュラ | 第8戦 SUGO 終了後 |
| SUPER GT | 第5戦鈴鹿終了時点 |
| スーパー耐久 | 公式「2026 STANDING」年間ランキングボード（第5戦終了時点） |

#### チーム名・画像

- チーム名は公式ページへのリンクにする
- 公式マシン画像が取れる場合は、名前の上にサムネイル（幅 150px、高さ 84px、`object-fit: cover`）を置く
- 画像が取れない場合はチーム名リンクのみにする。「画像未確認」とは書かない

#### 人物リンク

- ドライバーとレースアンバサダーは、確認できた SNS を1つだけ付ける
- 優先順は X、なければ Instagram
- 確認できない場合は氏名のみ。空欄は空欄のままにする
- 「本人投稿含め未確認」「公式発表未確認」などの注記は出さない

#### 掲載範囲

| カテゴリー | チーム | ドライバー |
| --- | --- | --- |
| スーパーフォーミュラ | 全チーム | 全ドライバー（0ポイント勢も含む） |
| SUPER GT | GT500・GT300 の全チーム | 車両ごとのドライバー組。公式が個人別に出している場合はそれに合わせる |
| スーパー耐久 | 各クラス上位3チーム。3台未満のクラスは全車 | 個人ランキングは作らない。チーム行にドライバーを併記する。ST-Q は対象外 |

### レスポンシブ

- トップページは 760px 以下でカード型に組み替え、各セル先頭にカテゴリー名と公式ロゴを出す
- ランキング表は横スクロール（`overflow-x: auto`）で列を維持する
- ビューポート指定は全ページ共通

### 更新時の注意

- カテゴリー色を入れ替えない
- 未確認情報を埋めない。空欄でよい
- 公式の並び・ポイント表記に合わせる（同点時の公式順を優先）
- スーパー耐久のクラス名や車両名は公式ボードの表記を使う

## トップページ

ファイル: `2026_japanese_car_race_category/index.html`  
サイトの実質トップ。3カテゴリーを横並びで見る。

### 役割

スーパーフォーミュラ、SUPER GT、スーパー耐久の違いを、規定・実施規模・年間日程から把握する。ランキングの詳細は各カテゴリーページへ渡す。

### 画面構成

```text
h1  日本国内自動車レーストップカテゴリー（2026年8月時点）
p   要約（主要3カテゴリーの概要と年間日程）
nav 分類アンカー ＋ 各ランキングページへのリンク
table
  thead  分類 / 内訳 / SF / GT / S耐（各公式ロゴ付き）
  tbody  本文行
  caption 出典とバッジ凡例
```

### ナビゲーション

ページ内アンカーと、ランキングページへのリンクを同じピル型ナビに並べる。

| リンク | 行き先 |
| --- | --- |
| 車両レギュレーション | `#vehicle-regulations` |
| 競技レギュレーション | `#sporting-regulations` |
| 2026年実施概要 | `#season-overview` |
| 2026年日程 | `#season-schedule` |
| SFランキング | `super_formula/` |
| SUPER GTランキング | `super_gt/` |
| S耐ランキング | `super_taikyu/` |

列見出しのロゴは各公式トップへ開く。

### テーブル設計

列は左から「分類」「内訳」、続けて3カテゴリー。行はグループ単位でまとめ、先頭行に `group-start` と `id` を付ける。

| 分類 | 内訳 | 行数 |
| --- | --- | --- |
| カテゴリー概要 | 競技の特徴 | 1 |
| 車両レギュレーション | 車体／パワーユニット／タイヤ | 3 |
| 競技レギュレーション | 予選／決勝／走行距離・時間／ドライバー交代／給油・タイヤ交換 | 5 |
| 2026年実施概要 | チーム数・ドライバー数／競技回数 | 2 |
| 2026年日程 | 1月〜12月 | 12 |

- 「分類」は `rowspan` でグループをまとめる
- 「車体」行は公式車両画像を置き、画像自体も公式解説ページへリンクする
- 日程セルは開催日・サーキット・所在地を書く。開催なしの月は `.note` で「開催なし」またはオフシーズンと書く
- 公式カレンダーやチケット案内がある場合は、色付きバッジ（`.src`）をセル内に置く

### 出典バッジ

| クラス | 色 | 意味 |
| --- | --- | --- |
| `.src.sf` | 緑 | スーパーフォーミュラ側の出典 |
| `.src.gt` | 赤 | SUPER GT 側の出典 |
| `.src.st` | 青 | スーパー耐久側の出典 |
| `.src.circuit` | 紫 | 開催サーキットの公式カレンダー |
| `.src.ticket` | 橙 | チケット購入・案内 |

凡例は表下キャプションに置く。キャプションでは、レギュレーションは2026年の最新情報のみ、日程・規定は2026年8月時点で今後変わり得ると明記する。

### ビジュアル

- 表頭はネイビー。3カテゴリー列だけ淡いカテゴリー色の背景にする
- 分類セルはラベル背景、内訳セルは薄いグレー
- グループ先頭行はネイビーの上罫で区切る
- 表は白カード＋軽い影。最大幅 1400px

### レスポンシブ

760px 以下では次の形に切り替える。

- `thead` を隠す
- 各 `tr` をカードにする
- 分類セルをネイビー帯、内訳セルをラベル帯にする
- 3カテゴリーのセル先頭にカテゴリー名と公式ロゴを `::before` で出す
- ナビは2列グリッドに広げる
- 見出しと要約は左寄せにする

761px〜1180px では余白と最小幅だけ詰める。

### コンテンツ方針

- 3列の粒度を揃える。片側だけ詳細になりすぎない
- 数値や回数は公式発表に合わせ、セル内で出典へリンクする
- SUPER GT のセパン大会延期など、シーズン中の変更は公式発表どおり書く

## スーパーフォーミュラ

ファイル: `2026_japanese_car_race_category/super_formula/index.html`

### 役割

2026年スーパーフォーミュラのチーム選手権とドライバー選手権を、チーム周辺情報と一緒に見るページ。個人の速さが勝敗の中心になるカテゴリーなので、ドライバー表は1人1行にする。

### 画面構成

```text
h1  スーパーフォーミュラ 2026 ランキング・チーム情報
logo SUPER FORMULA 公式ロゴ
p    時点注記
nav  トップページ / SUPER GT / スーパー耐久
h2   チームランキング
table
h2   ドライバーランキング
table
```

時点注記: 2026年8月14日時点。第8戦 SUGO 終了後の公式ランキングを基準にする。

### キーカラー

`#1f7a4d`（緑）。見出し、表頭、ナビ枠に使う。

### チームランキング

公式 Team Standings の全16チームを順位どおり載せる。同点は公式の並び（高得点回数など）に従う。0ポイントのチームも末尾に載せる。

| 列 | 内容 |
| --- | --- |
| 順位 | 公式順位。0ポイントで順位空欄の場合はページ上は末尾相当として扱う |
| チーム | 公式ページリンク。可能なら2026マシン画像 |
| ポイント | チーム選手権ポイント（予選点は含まない） |
| メインスポンサー | 確認できた名称のみ |
| 監督 | 確認できた氏名のみ |
| ドライバー | 登録ドライバー。SNS が取れた人はリンク |
| レースアンバサダー | 公式発表がある場合のみ。SNS が取れた人はリンク |

チーム画像は名前の上に置き、画像と名前のセットで公式ページへリンクする。

### ドライバーランキング

公式 Driver Standings の全出走者を載せる。21位までが順位付き。以降の0ポイント勢は順位セルを空にする。

| 列 | 内容 |
| --- | --- |
| 順位 | 公式順位。未記載は空欄 |
| No. | カーナンバー |
| ドライバー | 氏名。SNS があればリンク |
| チーム | 所属チーム名（テキスト） |
| ポイント | ドライバー選手権ポイント |

同一号車をシーズン途中で交代した場合は、出走したドライバーを別行で載せる。

チームポイントとドライバーポイントが一致しないことがある。チーム選手権に予選点が入らないためで、公式どおり別々に書く。

### ナビゲーション

| リンク | 行き先 |
| --- | --- |
| トップページに戻る | `../` |
| SUPER GT | `../super_gt/` |
| スーパー耐久 | `../super_taikyu/` |

ロゴは `https://superformula.net/sf3/` へ開く。

### 出典

- チーム表: SUPER FORMULA 公式「2026 Team Standings」と各チーム公式ページ
- ドライバー表: SUPER FORMULA 公式「2026 Driver Standings」
- キャプションで「チーム名の画像は公式ページへのリンク」と書く

### レイアウト

- 本文最大幅 1280px
- 表は白カード、最小幅 880px、横スクロール可
- 順位・号車列は折り返さない

## SUPER GT

ファイル: `2026_japanese_car_race_category/super_gt/index.html`

### 役割

2026年 SUPER GT の GT500 / GT300 について、チーム選手権とドライバー選手権を見るページ。2クラスが同時に走るため、クラスごとに表を分ける。

### 画面構成

```text
h1  SUPER GT 2026 ランキング・チーム情報
logo SUPER GT 公式ロゴ
p    時点注記
nav  トップページ / スーパーフォーミュラ / スーパー耐久
h2   GT500 チームランキング
h2   GT500 ドライバーランキング（車両ごとのドライバー組）
h2   GT300 チームランキング
h2   GT300 ドライバーランキング（車両ごとのドライバー組）
```

時点注記: 2026年8月24日時点。第5戦鈴鹿終了時点の SUPER GT 公式掲載値を基準にする。TOYOTA GAZOO Racing 掲載値は公式サイトより更新が遅れることがあるため、両者が揃わない場合は SUPER GT 公式サイトを優先する。

ドライバー表の仕組みを説明する注記は置かない。見出しの「車両ごとのドライバー組」で足りる。

### キーカラー

`#b0182a`（赤）。見出し、表頭、ナビ枠に使う。

### 掲載範囲

- GT500: 全14台
- GT300: 全29台
- ドライバー表も公式掲載範囲を載せる。0ポイントで公式ドライバー表に無い車両は、末尾に順位空欄で載せてよい

同点の並びは SUPER GT 公式サイトの順を優先する。

### チームランキング

GT500・GT300 とも同じ列構成。

| 列 | 内容 |
| --- | --- |
| 順位 | 公式順位 |
| No. | カーナンバー |
| チーム | 公式ページリンク。可能なら2026マシン画像 |
| ポイント | 決勝順位ポイントと周回ポイントの合計 |
| 差 | 1位との差。1位は `-` |
| メインスポンサー | 確認できた名称のみ |
| 監督 | 確認できた氏名のみ |
| ドライバー | 登録ドライバー。SNS が取れた人はリンク |
| レースアンバサダー | 公式発表がある場合のみ |

ARTA 8号車と16号車のようにアンバサダーが共通なら、両行に同じメンバーを書いてよい。

### ドライバーランキング

原則は「1台を共有する登録ドライバーが同じポイント」なので、車両ごとの組で1行にする。

| 列 | 内容 |
| --- | --- |
| 順位 | 公式順位。未掲載の0ポイント勢は空欄 |
| No. | カーナンバー |
| ドライバー | 組の氏名。SNS があればリンク |
| ポイント | ドライバーポイント |
| 差 | 1位との差 |

GT300 は出走戦の違いで公式が個人別に分けている場合がある（例: 32号車、7号車、31号車）。そのときは公式どおり個人行に分ける。組に無理にまとめない。

### ナビゲーション

| リンク | 行き先 |
| --- | --- |
| トップページに戻る | `../` |
| スーパーフォーミュラ | `../super_formula/` |
| スーパー耐久 | `../super_taikyu/` |

ロゴは `https://supergt.net/` へ開く。

### 出典

- SUPER GT 公式のチーム／ドライバーランキング
- TOYOTA GAZOO Racing「SUPER GT 2026 ポイントランキング」
- 各チーム公式ページ
- キャプションで、チームポイントが決勝順位点と周回点の合計であること、画像が公式ページへのリンクであることを書く

### レイアウト

- 本文最大幅 1280px
- 表は白カード、最小幅 860px、横スクロール可
- 順位・号車列は折り返さない

## スーパー耐久

ファイル: `2026_japanese_car_race_category/super_taikyu/index.html`

### 役割

2026年スーパー耐久のクラス別チーム選手権を見るページ。複数ドライバーが1台を走らせるため、公式の中心はチーム／車両単位である。個人ランキング表は作らない。

### 画面構成

```text
h1  スーパー耐久 2026 チームランキング・ドライバー情報
logo スーパー耐久 公式ロゴ
p    時点注記
nav  トップページ / スーパーフォーミュラ / SUPER GT
h2   クラス別チームランキング・情報（車両単位）
table
```

時点注記: 2026年8月14日時点。公式「2026 STANDING」の年間ランキングボードを基準にする。

耐久レースであることの説明注記は置かない。見出しの「車両単位」で足りる。

### キーカラー

`#0b5fa5`（青）。見出し、表頭、ナビ枠に使う。

### 掲載範囲

年間ランキング対象の10クラスについて、各クラス上位3チームを載せる。

| クラス | 掲載 |
| --- | --- |
| ST-X / ST-Z / ST-TCR / ST-2 / ST-4 / ST-5F / ST-5R | 上位3 |
| ST-USA | 参戦1台のため1行のみ |
| ST-1 / ST-3 | 参戦2台のため2行のみ |
| ST-Q | 開発クラスのため載せる対象外 |

クラスの並びは公式ボードに合わせ、ST-X → ST-Z → ST-TCR → ST-USA → ST-1 → ST-2 → ST-3 → ST-4 → ST-5F → ST-5R とする。

### テーブル設計

1表に全クラスを縦に積む。クラスが変わるたびにクラス名を繰り返す。

| 列 | 内容 |
| --- | --- |
| クラス | ST-X など |
| 順位 | クラス内順位 |
| No. | カーナンバー |
